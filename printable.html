画蛇添足

huà shé tiān zú · To spoil a good result by adding something unnecessary

Student name 姓名: __________________________　Date 日期: _______________

成语意思 / Meaning

做了多余的事，反而破坏了原来的效果。

The extra addition is not merely unnecessary; it actually makes the result worse.

1. 选一选 / Choose the best answer

一张海报已经很清楚了。同学又加了十张不相关的图片，重点反而看不清了。这时可以说：

  1. 这是画蛇添足，原来更清楚。
  2. 这是一石二鸟，效率更高了。
  3. 这是对牛弹琴，别人不懂音乐。

2. 判断 / Does the idiom fit?

在每个情境后画圈：适合（✓）或不适合（✗）。

A. 作文缺少结尾，小明加上结尾，让故事更完整。　✓ / ✗

B. 菜已经很好吃了，小明又加了很多糖，结果变得太甜。　✓ / ✗

C. 报告的数据不完整，小明补上必要数据，让结论更准确。　✓ / ✗

3. 说一说 / Write a two-line dialogue

请设计一个日常生活情境，用“画蛇添足”提醒同学。注意语气，不要攻击对方。

Teacher answer key · 教师答案（打印时自动隐藏）

1. A. 2. A ✗ / B ✓ / C ✗. 3. Open-ended; look for an originally adequate result worsened by an unnecessary addition. Accept tactful usage.
