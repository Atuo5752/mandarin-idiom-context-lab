An independent, original, free interactive learning example for teachers and Mandarin learners.

- Idiom: **画蛇添足** (huà shé tiān zú)
- Meaning, literal translation, pinyin, contextual dialogue, instant-answer question
- Static HTML; no login, payments, backend, analytics or personal-data collection.
